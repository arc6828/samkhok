# สามโคก - แพลตฟอร์มภูมิปัญญาท้องถิ่นริมสองฝั่งเจ้าพระยา

เว็บไซต์รวบรวม เผยแพร่ และจัดการองค์ความรู้ ประวัติศาสตร์ วัฒนธรรม ภูมิปัญญาท้องถิ่น และสถานที่ท่องเที่ยวของ **อำเภอสามโคก จังหวัดปทุมธานี**

🌐 **เว็บไซต์:** [www.samkhok.org](https://www.samkhok.org)

---

## 📌 เกี่ยวกับโครงการ

**"โครงการพัฒนาแพลตฟอร์มการจัดการเรียนรู้สำหรับสถานศึกษาวิวัฒน์ชุมชนในเขตพื้นที่อำเภอสามโคก จังหวัดปทุมธานี"** เป็นโครงการวิจัยที่มีแนวคิดจากพระบรมราโชบายด้านการศึกษาของสมเด็จพระเจ้าอยู่หัวรัชกาลที่ 10 ในเรื่องของการศึกษาต้องมุ่งสร้างพื้นฐานให้แก่ผู้เรียนเพื่อยกระดับการจัดการเรียนรู้และอนุรักษ์ภูมิปัญญาท้องถิ่น

* **หน่วยงานวิจัย:** ทีมวิจัยคณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏวไลยอลงกรณ์ ในพระบรมราชูปถัมภ์
* **หัวหน้าโครงการ:** อ.วิศรุต ขวัญคุ้ม
* **ทุนสนับสนุน:** กองทุนส่งเสริมวิทยาศาสตร์ วิจัยและนวัตกรรม (กองทุน ววน.) ประเภท Fundamental Fund ประจำปีงบประมาณ 2565

---

## 🎯 วัตถุประสงค์

1. **สร้างแหล่งเรียนรู้ตลอดชีวิต (Lifelong Learning):** รวบรวมองค์ความรู้และศาสตร์ชุมชนสามโคกเพื่อส่งเสริมการเรียนรู้ภายในชุมชน
2. **อนุรักษ์และเผยแพร่ภูมิปัญญา:** ถ่ายทอดและเผยแพร่วัฒนธรรม ประเพณีท้องถิ่นเอกลักษณ์ (เช่น ชุมชนไทย-รามัญ/มอญ)
3. **พัฒนาทักษะเทคโนโลยีเพื่อการศึกษา:** ส่งเสริมให้ผู้สอนและบุคลากรทางการศึกษาสามารถนำเทคโนโลยีสารสนเทศและการสื่อสารไปประยุกต์ใช้ในการสร้างชุดสื่อการเรียนรู้

## 📂 หมวดหมู่เนื้อหา

แพลตฟอร์มดึงข้อมูลบทความผ่าน Feed API โดยแบ่งตามหมวดหมู่หลัก ได้แก่:

- 🏖️ **ท่องเที่ยว:** สถานที่ท่องเที่ยว โบราณสถาน และจุดพักผ่อนหย่อนใจริมแม่น้ำเจ้าพระยา
- 🎨 **วัฒนธรรม & ประเพณี:** ภูมิปัญญาพื้นบ้าน ประเพณีท้องถิ่น และวิถีชีวิต
- 🙏 **ความเชื่อ:** สิ่งศักดิ์สิทธิ์ ประวัติศาสตร์ และความเชื่อในท้องถิ่น
- 👤 **บุคคลสำคัญ:** บุคคลที่มีบทบาทสำคัญต่อประวัติศาสตร์และชุมชนสามโคก
- 💻 **การพัฒนาแพลตฟอร์ม & บทความพิเศษ:** สื่อการเรียนรู้และรายงานผลการดำเนินงานวิจัย

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Backend:** PHP (Vanilla PHP)
* **Data Integration:** Medium RSS Feed (Direct XML Parser & Local File Caching System)
* **Frontend:** HTML5, CSS3, JavaScript (jQuery, Bootstrap, AOS Animation, Owl Carousel, Autocomplete)
